# TaskHub

Простой CLI для задач на JSON-хранилище. Сейчас умеет:
- init — создать файл задач
- add — добавить задачу (с тэгами и датой если нужно)
- list — показать задачи, отфильтровать по статусу, тегу и части названия
- done — отметить задачу выполненной

Дальше будем допиливать.

## Поиск по названию

Из корня репозитория при `PYTHONPATH=practices/practice_04/src`:

```bash
python -m taskhub.app list --search "прак"
python -m taskhub.app list --search "практика" --status todo --tag учеба
```

Поиск — буквальная подстрока названия после `casefold()` обеих строк,
без учёта регистра, включая кириллицу. Фильтры объединяются по AND.
Пробелы учитываются буквально; дополнительной Unicode-нормализации,
транслитерации и замены ё/е нет. Без `--search` и при `--search ""`
поисковый фильтр отключён. Без совпадений вывод пуст, код выхода — 0.

## Desktop UI

Окно TaskHub показывает абсолютный путь к общему `tasks.json` и таблицу с названием,
статусом, сроком и тегами. Поиск, статус и точный тег объединяются по AND после нажатия
«Применить». Введённые, но ещё не применённые значения не влияют на «Обновить».
«Сбросить» очищает фильтры и сразу перечитывает все задачи. Порядок соответствует файлу;
сортировки по колонкам в UI нет.

Запуск из корня workspace в окружении Python с Tcl/Tk:

```bash
PYTHONPATH=practices/practice_04/src \
  practices/practice_04/.venv/bin/python -m taskhub.gui
```

UI и CLI используют `tasks.json` текущего рабочего каталога. Tkinter поставляется
вместе с поддержкой Tcl/Tk конкретного Python и не устанавливается через pip. Проверить
окружение можно командой `.venv/bin/python -c "import tkinter"`.

Форма добавления принимает обязательное название, необязательный срок в формате
`YYYY-MM-DDTHH:MM:SS.ffffffZ` (UTC) и один тег. В форме изменения каждое поле нужно
явно отметить флажком «Изменить»: неотмеченные значения сохраняются. Изменение тега
заменяет все прежние теги одним введённым значением, а пустое значение очищает теги.
Очистка существующего срока не поддерживается.

«Выполнено» доступно только для выбранной todo-задачи, «Изменить» — для любой
выбранной строки. После добавления, изменения и выполнения таблица перечитывается с
активными фильтрами, поэтому изменённая задача может исчезнуть из текущей выборки.

«Отменить изменения» откатывает выбранные 1–3 последних изменения всего файла, включая
операции CLI, независимо от текущих фильтров. После отката активные фильтры сохраняются.

«Проверить данные» читает весь `tasks.json`, показывает доступные счётчики и все
найденные проблемы в отдельном отчёте. Проверка не исправляет и не создаёт файл, не
меняет историю и остаётся доступной, даже если таблица не смогла загрузиться.

При ошибке чтения таблица очищается, а изменяющие действия блокируются. После внешнего
исправления файла нажмите «Обновить»; фильтры и проверка данных остаются доступными.
Если запись уже выполнена, но перечитать список не удалось, UI сообщает об этих двух
фактах отдельно и не предлагает повторять запись.
