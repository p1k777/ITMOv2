# Proposal

## Why

После поиска и фильтрации пользователю удобно просматривать задачи по названию.
Явная сортировка делает результат предсказуемым, сохраняя привычный порядок без новой опции.

## What Changes

- Добавить `list --sort title`: стабильная сортировка по `title.casefold()` по возрастанию.
- Применять сортировку после существующих фильтров status, tag и search.
- Сохранять исходный порядок при одинаковых ключах и при отсутствии `--sort`.
- Отклонять неподдерживаемое или отсутствующее значение опции с ненулевым кодом выхода.
- Сохранить формат строк, содержимое существующего tasks.json и историю undo.
- Уточнить спецификацию поиска: исходный порядок гарантируется без явной сортировки.
- Вне границ: обратный порядок, другие ключи, локаль-зависимая сортировка,
  новые зависимости, изменение Storage API и MCP tools.

## Capabilities

### New Capabilities

- `task-sorting`: опциональная сортировка CLI-списка задач по названию.

### Modified Capabilities

- `task-search`: уточнить гарантии порядка и сравнения CLI со Storage
  при явно запрошенной сортировке; семантика поиска сохраняется.

## Impact

- `src/taskhub/app.py`: опция, проверка значения и сортировка результата перед выводом.
- `tests/test_sort.py`: новые CLI-сценарии по образцу `tests/test_search.py`.
- `PROJECT_README.md`: пример использования новой опции.
- Модель, JSON-схема, API `Storage.list_tasks` и история остаются прежними.
- Существующая автоинициализация отсутствующего хранилища сохраняется.
