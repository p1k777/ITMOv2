# Proposal

## Why

TaskHub уже предоставляет операции над задачами, поиск, фильтры, историю откатов
и проверку целостности, но не имеет оконного интерфейса. Нужен минимальный полный
desktop UI, открывающий доступ ко всем готовым возможностям существующего продукта.

## What Changes

- Добавить отдельную точку входа `python -m taskhub.gui` на Tkinter/ttk.
- Одно основное окно: таблица задач, поиск по названию, фильтры статуса и точного
  тега, кнопки «Применить», «Сбросить», «Обновить» и строка состояния.
- Общая небольшая форма добавления/редактирования: название, необязательный срок
  в существующем ISO UTC формате и один тег. В edit поля меняются только по выбору
  пользователя; очистка срока не добавляется, существующие множественные теги
  сохраняются, если поле тегов не изменялось.
- Действия: отметить выбранную todo выполненной; отменить 1–3 изменения;
  проверить целостность всего файла с отображением результата и списка проблем.
- После успешных записей и undo перечитывать список с сохранением активных фильтров.
- Использовать текущее хранилище относительно рабочего каталога, показывать его
  абсолютный путь, поддержать пустой список и видимые ошибки без ложного успеха.
- Документировать запуск и проверку наличия Tcl/Tk. Обновить AGENTS.md при реализации:
  разрешить отдельный desktop UI как расширение правила «минимальный CLI».
- Сортировка считается неготовой: ни переключателя сортировки, ни сортировки
  по заголовкам колонок в UI нет. Порядок определяется существующим Storage.
- Границы: без удаления, очистки срока, нового формата данных, выбора файла,
  HTTP, фоновых потоков и новых pip-зависимостей. Проверка целостности только читает
  файл, не исправляет его и доступна даже при ошибке загрузки таблицы.

## Capabilities

### New Capabilities

- `desktop-task-management`: оконный доступ к готовым операциям задач, поиску,
  фильтрам, редактированию, откату и проверке целостности с обработкой ошибок.

### Modified Capabilities

Нет. Существующая `task-search` описывает CLI/Storage и сохраняет свой контракт.

## Impact

- Новый модуль `src/taskhub/gui.py`: окно, общая форма и тонкий тестируемый контроллер
  над существующими Task, Storage и `validate_file` из `validate.py`.
- Новые проверки в `tests/test_gui.py`, инструкции в PROJECT_README.md и AGENTS.md.
- Формат tasks.json, история и API Storage, модель, CLI и MCP сохраняются.
- Tkinter требует Python с Tcl/Tk и графическую сессию для оконных проверок;
  это системная предпосылка, не новая зависимость pyproject.toml.
- В текущем `python3` недоступны `_tkinter` и pytest. Настройка окружения нужна
  перед реализацией/проверками; изменения системного Python этим планом не выполняются.
