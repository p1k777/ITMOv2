# Quickstart: Валидация сортировки задач в GUI TaskHub

## Предварительные условия

- Python 3.11+
- Зависимости проекта установлены (typer, pytest для dev)
- Tcl/Tk доступен для запуска GUI

## Команда запуска GUI

```bash
export PYTHONPATH=practices/practice_04/src
python -m taskhub.gui
```

## Сценарии валидации

### Сценарий 1: Сортировка по возрастанию (asc)

1. Запустить GUI, добавить несколько задач с разными названиями
2. Кликнуть на заголовке "Название"
3. **Ожидаемый результат**: Задачи отсортированы по названию по возрастанию, в заголовке отображается "Название ▲", остальные заголовки без стрелок

### Сценарий 2: Сортировка по убыванию (desc)

1. При предыдущем состоянии (Название ▲) снова кликнуть на заголовке "Название"
2. **Ожидаемый результат**: Задачи отсортированы по убыванию, заголовок отображается "Название ▼"

### Сценарий 3: Сброс сортировки

1. При состоянии "Название ▼" снова кликнуть на заголовке "Название"
2. **Ожидаемый результат**: Задачи возвращаются в исходный порядок из файла, заголовок отображается "Название" без стрелки

### Сценарий 4: Переключение колонки

1. При сортировке по "Название" кликнуть на заголовке "Статус"
2. **Ожидаемый результат**: Задачи отсортированы по статусу по возрастанию, индикатор на "Название" исчезает, на "Статус" отображается "Статус ▲"

### Сценарий 5: Сохранение сортировки при смене фильтров

1. Отсортировать задачи по "Срок" (asc)
2. Применить фильтр по статусу "todo"
3. **Ожидаемый результат**: Таблица обновляется с фильтром, сортировка по "Срок" (asc) сохраняется, заголовок "Срок ▲" остаётся

### Сценарий 6: Пустой список задач

1. Открыть GUI без задач (или удалить все задачи)
2. Кликнуть на любой заголовок колонки
3. **Ожидаемый результат**: Приложение не выдаёт ошибок, заголовок остаётся кликабельным, таблица остаётся пустой

### Сценарий 7: Не меняется порядок в файле

1. Отсортировать задачи по любой колонке
2. Закрыть и снова открыть GUI
3. **Ожидаемый результат**: Задачи отображаются в исходном порядке из файла (сортировка не сохраняется между сессиями)

## Ожидаемые команды для проверки

```bash
# Запуск существующих тестов (должны остаться зелёными)
pytest -q

# Запуск линтера
python3 tools/lint.py

# Запуск GUI вручную
export PYTHONPATH=practices/practice_04/src
python -m taskhub.gui
```
