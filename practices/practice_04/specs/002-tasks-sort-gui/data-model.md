# Data Model: Сортировка задач в GUI TaskHub

## Entities

### SortState

Состояние сортировки GUI, хранящееся в объекте `TaskHubWindow`.

| Поле | Тип | Допустимые значения | Описание |
|------|-----|---------------------|----------|
| `sort_by` | `str \| None` | "title", "status", "due_date", "tags", None | Текущая колонка сортировки. None = без сортировки |
| `sort_order` | `str` | "asc", "desc" | Направление сортировки |

**Состояние по умолчанию**: `sort_by=None`, `sort_order="asc"` (при запуске GUI)

**Маппинг колонок GUI → backend**:
- "Название" → "title"
- "Статус" → "status"
- "Срок" → "due_date"
- "Теги" → "tags"

**Состояние "без сортировки"**: `sort_by=None` соответствует отсутствию сортировки, задачи возвращаются в порядке из файла.

## Validation Rules

- `sort_by` должен быть одним из: "title", "status", "due_date", "tags", None
- `sort_order` должен быть "asc" или "desc"
- При `sort_by=None` направление сортировки не применяется (соответствует `sort_order="asc"` по умолчанию)
- При клике на уже активную колонку направление переключается циклически: asc → desc → None (сброс)
- При клике на другую колонку: устанавливается новая колонка, направление = "asc", предыдущий индикатор сбрасывается

## State Transitions

```
Не отсортировано (None)
    ├─ клик на колонку X → (X, asc)
    │       ├─ повторный клик на X → (X, desc)
    │       │       └─ повторный клик на X → (None, asc)  [сброс]
    │       └─ клик на колонку Y → (Y, asc)
    └─ клик на другую колонку Y → (Y, asc)  [сброс X, установка Y]
```

## Relationships

- **SortState → Task**: SortState определяет параметры `sort_by`/`sort_order` для вызова `controller.list_tasks()`, который возвращает отсортированный список объектов `Task`.
- **SortState → Table view**: При изменении SortState вызывается `refresh()`, который перерисовывает таблицу с индикатором сортировки в заголовке активной колонки.

## Constraints

- SortState не сохраняется между сессиями приложения (сбрасывается при запуске)
- SortState сохраняется при смене фильтров ("Применить" / "Сбросить")
- GUI не поддерживает сортировку по `created_at` (доступны только 4 колонки)
