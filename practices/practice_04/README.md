# Practice 04: TaskHub

Это простой CLI для списка задач. Можно добавлять задачи, смотреть список и отмечать выполненные.

Как запустить:
- Нужен Python 3.11+
- Тесты: `pytest -q`

Что есть:
- src/taskhub/: ядро CLI и хранилище
- tests/: базовые тесты
- AGENTS.md: заметки для агента

Пока всё. Фичи будем добавлять позже.
