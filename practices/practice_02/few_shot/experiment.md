# Few-shot

- Артефакт Практики 1: `practices/practice_01/project_management.md`
- Что хотим улучшить: неполнота правил (нет QA-1/OBS-1/SCOPE-1), непроверяемые проверки, неясные зависимости, нереалистичная диаграмма, некорректная ссылка на prompts

## Примеры

### Хороший результат

```
| 1 | API-1: HTTP 413 для diff > 20000 | Утверждает правило отсечки | Добавляет guard в FastAPI и тесты | Integration: diff длиной 20001 → 413; 19999 → 200. Acceptance: 413 для >20000, 200 иначе | CASE.md API-1 |
```

### Плохой результат

```
| n | Улучшить надёжность | Настраивает таймаут | Пишет тесты | Смотрим, чтобы всё работало | — |
```

## Запрос

```
Исправь `practices/practice_01/project_management.md` без изменения исходника. Сохрани структуру: «План поставки», «Инкременты и ответственность», «Диаграмма Ганта», «Как использовали AI». Добавь недостающие правила QA-1/OBS-1/SCOPE-1 и обеспечь полную трассировку на SEC-1/API-1/REL-1/OUT-1/QA-1/OBS-1/SCOPE-1. Формулируй проверки как проверяемые (unit/integration/e2e/contract) с входами, условиями, ожидаемыми исходами и критерием успеха. Обнови диаграмму Ганта (mermaid) по реальным зависимостям. В разделе AI укажи тип промпта — few-shot; строка в prompts.md — P2-CoVe-01. Запиши результат в `practices/practice_02/few_shot/project_management_fixed.md`.
```
